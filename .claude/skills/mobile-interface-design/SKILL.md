# Native Mobile Interface Design

Read `.engineer-intelligence/senior/frontend/design/mobile-interface/SKILL.md`
and `.engineer-intelligence/senior/frontend/design/SKILL.md` for native mobile
interface work; follow the Design skill's project-surface discovery guidance to
select the owning app/package. If
`.engineer-intelligence/senior/frontend/mobile/SKILL.md` exists, pair it for
implementation architecture. If it is absent, follow the target project's mobile
instructions and established framework conventions; this Design-only package
does not install Mobile Engineering. Keep platform navigation, safe areas,
keyboard/input, touch, accessibility, state and supported device transformations
explicit. Do not treat a native app as a shrunken web page.

For code-only performance or maintenance fixes with no interface decision, use
Mobile Engineering without this Design specialization.
