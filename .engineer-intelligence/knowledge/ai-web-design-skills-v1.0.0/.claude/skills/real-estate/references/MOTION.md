# Real Estate Motion Intelligence

## Strong opportunities

- listing-to-detail image continuity
- gallery transitions
- map/list state transitions
- floorplan reveal
- subtle spatial parallax

## Motion decision

Use motion only when it:

- reinforces the brand
- reveals a relationship or process
- preserves spatial continuity
- provides useful feedback

## Avoid

- cinematic friction on search portals
- fake property imagery
- overlong intro loaders
- hiding price/location
- parallax on every image

## Production fallback

On mobile and reduced-motion contexts, preserve the same information and narrative using a simpler vertical/static form.
