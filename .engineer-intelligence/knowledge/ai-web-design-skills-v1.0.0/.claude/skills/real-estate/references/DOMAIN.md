# Real Estate Domain Model

## Subtypes

- luxury property
- brokerage
- property developer
- apartment project
- commercial property
- vacation property
- marketplace

## Primary audiences

- buyers
- investors
- renters
- property owners
- developers

## Common conversions

- view listings
- request viewing
- contact agent
- download project information
- compare/save property

## Trust signals

- real photography
- location facts
- floor plans
- developer/broker credentials
- transparent property details
- availability/status

## Discovery questions for the agent

- Which subtype is this?
- Who makes the purchase/decision?
- Is the site primarily discovery, evaluation, transaction, booking, or lead generation?
- What proof exists and what must not be fabricated?
- What content/media is actually available?
- What industry cliché should be deliberately avoided?
