# Real Estate Design Intelligence

Do not code this industry as a generic template.

## Required workflow

1. Classify the business subtype using `references/DOMAIN.md`.
2. Identify the primary audience and conversion.
3. Read `references/DIRECTIONS.md` and choose one direction with rationale.
4. Build the page narrative using `references/PAGE-PATTERNS.md`.
5. If motion is desired, read `references/MOTION.md` and combine with `motion-direction`.
6. Before completion, run `references/QA.md` plus global quality gates.

## Industry priority

The experience must optimize for:

- relevance to audience
- trust
- clarity of offer
- conversion
- distinctive visual expression appropriate to the subtype

Do not copy the same art direction across all subtypes.
