# Art Direction

## Goal

Turn business positioning into a visual system.

## Decision model

### 1. Emotional target

Choose 3–5 adjectives that the site must embody.
Examples: precise, discreet, spatial, sensual, technical, optimistic, authoritative.

Choose 3 anti-adjectives.
Examples: playful, noisy, corporate, childish, futuristic.

### 2. Visual direction

Select one primary direction and at most one supporting direction:

- editorial
- restrained luxury
- modernist/minimal
- cinematic
- technical/systemic
- expressive/playful
- brutalist
- futuristic
- corporate/institutional
- organic/tactile

Do not combine labels without explaining what each contributes.

### 3. Typography

Define roles rather than random font sizes:

- display
- section title
- body
- metadata
- labels / controls
- numeric / technical data if relevant

Decide contrast:

- serif display + neutral sans body
- grotesk + mono accents
- single-family variable system
- humanist family for approachable services

### 4. Layout grammar

Define:

- max content width
- outer gutters
- column grid
- alignment logic
- dense vs spacious sections
- image edge behavior
- asymmetry rules
- repeated visual motif

### 5. Imagery

Choose an art direction:

- documentary
- cinematic
- editorial crop
- product macro
- material/texture
- diagrammatic
- generated illustration only when appropriate

### 6. Signature idea

Create one memorable interaction or composition derived from the business.

Examples:

- architecture: project index controls a full-bleed spatial preview
- SaaS: actual workflow states animate through one continuous canvas
- legal: case/industry expertise is navigated like an editorial index
- real estate: listing image becomes detail hero through spatial continuity

## Anti-template test

Ask:
“Could this page be relabeled for a different industry without redesign?”
If yes, revisit direction.
