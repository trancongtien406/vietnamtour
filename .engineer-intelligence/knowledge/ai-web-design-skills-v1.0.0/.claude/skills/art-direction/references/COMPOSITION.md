# Composition

## Rhythm

A strong long page alternates:

- compression and release
- full-bleed and contained
- image-led and text-led
- static and interactive
- centered and directional composition

## Avoid

- same container width + same padding every section
- repeated centered headings
- endless card grids
- arbitrary alternation without narrative purpose

## Signature motif examples

Architecture: plan-like lines, spatial cropping, project index.
Legal: editorial index, evidence/case structure, refined rules.
SaaS: product state transitions and workflow.
Hospitality: destination chapters and immersive media.
Automotive: technical detail transitions and model states.
