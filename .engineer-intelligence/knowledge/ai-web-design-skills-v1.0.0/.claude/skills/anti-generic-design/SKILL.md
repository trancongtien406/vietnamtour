# Anti Generic Design

## Red flags

One red flag is not automatically wrong. Repetition without strategy is the problem.

Flag:

- default blue/purple gradient identity
- generic glowing AI orb
- glass panels everywhere
- floating dashboard screenshots with no story
- excessive rounded cards
- bento used for unrelated content
- repeated 3-column feature grid
- badge + centered H2 + paragraph in every section
- same max-width container rhythm for the entire page
- random icon circles
- gradient text as a substitute for hierarchy
- every element fade-up on scroll
- decorative particles with no brand meaning
- fake terminal purely to signal “developer”
- beige serif minimalism for every premium brand

## Repair loop

1. Restate the business in one sentence.
2. Identify what is visually unique about its work, process, environment, data, material, people, or outcome.
3. Build one motif from that source.
4. Vary composition and density.
5. Remove weak decoration.
6. Make motion reveal relationships, process, or spatial continuity.
7. Compare against the industry skill's anti-patterns.
8. Run the relabel test: if swapping logo/copy makes it work for another industry, redesign.
