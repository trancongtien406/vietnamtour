# Fashion / Apparel Art Directions

## Editorial luxury

**Use when:** luxury and designer

**Language:** oversized type, fashion photography, sparse controls

## Expressive independent

**Use when:** independent labels

**Language:** unusual grid, character typography, interactive imagery

## Product-first commerce

**Use when:** DTC apparel

**Language:** strong merchandising, editorial accents, fast shopping UX

## Selection rule

Choose one primary direction. Add a secondary direction only if it solves a specific brand tension.
State why the chosen direction fits this business subtype and audience.

## Do not

Do not use a style simply because it is trending.
Do not default to generic gradients, cards, or cinematic motion when the domain needs utility.
