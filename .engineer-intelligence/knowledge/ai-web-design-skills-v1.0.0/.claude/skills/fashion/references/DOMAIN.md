# Fashion / Apparel Domain Model

## Subtypes

- luxury fashion
- independent designer
- streetwear
- editorial commerce
- accessories

## Primary audiences

- brand followers
- fashion shoppers
- editors/buyers
- collectors

## Common conversions

- explore collection
- shop product
- view lookbook
- join release/newsletter

## Trust signals

- real collection imagery
- materials/details
- fit/sizing
- shipping/returns for commerce
- press/stockists if relevant

## Discovery questions for the agent

- Which subtype is this?
- Who makes the purchase/decision?
- Is the site primarily discovery, evaluation, transaction, booking, or lead generation?
- What proof exists and what must not be fabricated?
- What content/media is actually available?
- What industry cliché should be deliberately avoided?
