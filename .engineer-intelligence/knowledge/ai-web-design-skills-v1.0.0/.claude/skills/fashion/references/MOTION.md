# Fashion / Apparel Motion Intelligence

## Strong opportunities

- mask reveals
- slow image zoom
- lookbook transitions
- cursor preview for editorial index
- collection page transitions

## Motion decision

Use motion only when it:

- reinforces the brand
- reveals a relationship or process
- preserves spatial continuity
- provides useful feedback

## Avoid

- UI-heavy card dashboards
- motion that slows product purchase
- cheap gold/black luxury cliché
- random tech gradients

## Production fallback

On mobile and reduced-motion contexts, preserve the same information and narrative using a simpler vertical/static form.
