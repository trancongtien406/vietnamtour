# Restaurant / Cafe / Food Motion Intelligence

## Strong opportunities

- food/space image reveal
- menu section transitions
- reservation CTA feedback
- subtle ingredient/material motion

## Motion decision

Use motion only when it:

- reinforces the brand
- reveals a relationship or process
- preserves spatial continuity
- provides useful feedback

## Avoid

- hiding menu behind animation
- autoplay sound
- long cinematic intro before hours/location
- generic stock food

## Production fallback

On mobile and reduced-motion contexts, preserve the same information and narrative using a simpler vertical/static form.
