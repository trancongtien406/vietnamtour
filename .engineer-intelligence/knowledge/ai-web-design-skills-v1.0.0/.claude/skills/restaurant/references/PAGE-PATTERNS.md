# Restaurant / Cafe / Food Page Patterns

## Recommended narrative modules

- hero + reserve/order
- signature dishes
- menu access
- story/chef
- space/atmosphere
- hours/location
- reviews/press
- reservation

## Section design rules

- Each section must answer one buyer/user question.
- Proof should appear near the claim it supports.
- Avoid repeating the same card grid structure.
- Vary full-bleed, contained, editorial, and utility sections according to content.
- Primary CTA must remain easy to find on mobile.

## Page construction

Start with the decision journey, then choose components.
Do not invent proof, statistics, clients, awards, reviews, case results, certifications, availability, pricing, or outcomes.
