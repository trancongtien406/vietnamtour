# Automotive / Mobility Art Directions

## Performance cinematic

**Use when:** sports/performance

**Language:** dramatic media + spec rhythm

## Technical premium

**Use when:** premium vehicles

**Language:** engineering details + restrained luxury

## Mobility system

**Use when:** EV/mobility

**Language:** clean future-facing product/system story

## Selection rule

Choose one primary direction. Add a secondary direction only if it solves a specific brand tension.
State why the chosen direction fits this business subtype and audience.

## Do not

Do not use a style simply because it is trending.
Do not default to generic gradients, cards, or cinematic motion when the domain needs utility.
