# Automotive / Mobility Domain Model

## Subtypes

- performance vehicle
- luxury vehicle
- dealership
- EV/mobility
- fleet/commercial

## Primary audiences

- buyers
- enthusiasts
- fleet managers
- investors

## Common conversions

- configure/explore model
- book test drive
- contact dealer
- request quote

## Trust signals

- real vehicle media
- specifications
- pricing/availability where relevant
- dealer/service details
- safety/technical facts

## Discovery questions for the agent

- Which subtype is this?
- Who makes the purchase/decision?
- Is the site primarily discovery, evaluation, transaction, booking, or lead generation?
- What proof exists and what must not be fabricated?
- What content/media is actually available?
- What industry cliché should be deliberately avoided?
