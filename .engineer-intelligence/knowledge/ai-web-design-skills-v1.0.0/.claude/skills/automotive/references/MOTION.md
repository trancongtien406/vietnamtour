# Automotive / Mobility Motion Intelligence

## Strong opportunities

- vehicle reveal
- spec transitions
- detail hotspots
- model/color state transitions
- scroll feature chapters

## Motion decision

Use motion only when it:

- reinforces the brand
- reveals a relationship or process
- preserves spatial continuity
- provides useful feedback

## Avoid

- fake 3D for prestige
- slow configurator
- excessive particle effects
- hiding technical facts

## Production fallback

On mobile and reduced-motion contexts, preserve the same information and narrative using a simpler vertical/static form.
