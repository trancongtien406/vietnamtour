# Motion for React

Prefer Motion for:

- AnimatePresence-style enter/exit
- layout/shared-element transitions
- modal/menu/drawer
- drag and gestures
- spring UI feedback
- small route/component transitions

Prefer CSS for trivial hover/state transitions.
Prefer GSAP for complex scroll/timeline orchestration.

Keep motion semantics tied to UI state.
Avoid wrapping every component merely to animate it.
