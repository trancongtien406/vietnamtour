# SaaS Domain Model

## Subtypes

- B2B workflow
- CRM
- developer tool
- operations platform
- vertical SaaS
- collaboration product

## Primary audiences

- operators
- teams
- technical evaluators
- buyers
- end users

## Common conversions

- start trial
- book demo
- create account
- understand product

## Trust signals

- real product UI
- specific outcomes
- customer proof
- security/integration details
- transparent pricing where appropriate

## Discovery questions for the agent

- Which subtype is this?
- Who makes the purchase/decision?
- Is the site primarily discovery, evaluation, transaction, booking, or lead generation?
- What proof exists and what must not be fabricated?
- What content/media is actually available?
- What industry cliché should be deliberately avoided?
