# SaaS Motion Intelligence

## Strong opportunities

- workflow state transitions
- before/after process
- shared product panels
- interactive demo states
- data flow

## Motion decision

Use motion only when it:

- reinforces the brand
- reveals a relationship or process
- preserves spatial continuity
- provides useful feedback

## Avoid

- generic purple gradient
- floating fake dashboards
- bento everywhere
- meaningless glow
- abstract orb instead of product

## Production fallback

On mobile and reduced-motion contexts, preserve the same information and narrative using a simpler vertical/static form.
