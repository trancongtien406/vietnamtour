# Typography Motion

## Match effect to voice

Editorial/luxury:

- line mask
- word clip
- slow character/word stagger

Technical:

- number transition
- restrained scramble
- status/state type changes

Playful:

- rolling labels
- spring accents
- interactive type

## Rules

- body copy should appear quickly
- do not scramble critical text
- preserve semantic text in DOM
- avoid splitting everything into characters
- reduced motion shows final text immediately
