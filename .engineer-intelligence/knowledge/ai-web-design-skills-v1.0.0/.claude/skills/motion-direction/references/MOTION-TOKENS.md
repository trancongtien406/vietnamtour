# Motion Tokens

Use a small, brand-specific system.

## Suggested classes

- feedback: 120–180ms
- fast UI: 180–260ms
- standard UI: 260–420ms
- reveal: 420–700ms
- narrative: 700–1100ms
- cinematic: >1100ms only with clear value

## Distance

Small UI: 4–12px.
Section reveal: 16–48px.
Large spatial transitions: derive from actual geometry, not arbitrary 100px offsets.

## Stagger

Use the shortest stagger that still communicates sequence.
Long stagger over navigation/menu items feels slow.
