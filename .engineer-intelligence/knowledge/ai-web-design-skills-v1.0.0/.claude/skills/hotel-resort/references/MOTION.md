# Hotel / Resort / Hospitality Motion Intelligence

## Strong opportunities

- room/gallery transitions
- destination chapters
- slow parallax
- map/location reveals
- booking-panel state transitions

## Motion decision

Use motion only when it:

- reinforces the brand
- reveals a relationship or process
- preserves spatial continuity
- provides useful feedback

## Avoid

- burying booking CTA
- slow mobile hero video with no fallback
- overlong loader
- motion-heavy booking forms

## Production fallback

On mobile and reduced-motion contexts, preserve the same information and narrative using a simpler vertical/static form.
