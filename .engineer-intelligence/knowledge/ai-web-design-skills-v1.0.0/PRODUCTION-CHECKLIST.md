# Production Checklist

## Discovery

- [ ] Business type/subtype identified
- [ ] Primary audience identified
- [ ] Primary conversion identified
- [ ] Trust requirements identified
- [ ] Content availability / asset quality assessed
- [ ] Competitor clichés identified

## Direction

- [ ] 3–5 desired brand adjectives
- [ ] 3 anti-adjectives
- [ ] visual direction selected with rationale
- [ ] typography roles defined
- [ ] grid / spacing rhythm defined
- [ ] imagery / art direction defined
- [ ] one signature visual idea defined

## Motion

- [ ] motion personality defined
- [ ] duration / easing / stagger family defined
- [ ] entrance / exit grammar defined
- [ ] page transition strategy defined
- [ ] scroll effects justified
- [ ] implementation library chosen per effect
- [ ] reduced-motion fallback defined

## Engineering

- [ ] semantic structure
- [ ] keyboard access
- [ ] responsive behavior
- [ ] no hover-only access
- [ ] lifecycle cleanup
- [ ] optimized image/video
- [ ] no accidental layout thrashing
- [ ] no duplicated ScrollTriggers/listeners
- [ ] animation failure does not block navigation/content

## QA

- [ ] visual hierarchy review
- [ ] industry-fit review
- [ ] anti-generic review
- [ ] motion review
- [ ] mobile review
- [ ] reduced-motion review
- [ ] performance review
