# Web Design Project Instructions

Use `web-design-production` for substantial website creation/redesign work.

Always:

- understand business/audience/conversion before implementation
- use the relevant industry skill
- define art direction before selecting animation
- keep motion purposeful
- preserve mobile and reduced-motion behavior
- run UI, motion, and performance quality gates before completion

Never fabricate:

- customer logos
- metrics
- testimonials
- awards
- legal results
- medical claims
- property availability
- pricing
- security certifications

Use real project content when available; otherwise use clearly marked placeholders.
