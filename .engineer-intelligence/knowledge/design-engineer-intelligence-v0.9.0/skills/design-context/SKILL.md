# Design Context Model

Capture only decision-relevant context:

- product type, purpose, maturity, business model;
- primary users, expertise, frequency and environment;
- primary/secondary jobs, urgency and complexity;
- surface, viewport/input modes and density;
- brand personality and existing identity;
- desired feeling, trust requirement and exploration level;
- framework, existing components, performance and accessibility constraints.

Never map industry directly to a visual stereotype. Context is evidence, not a theme generator.
