# Navigation Behavior

Navigation must remain discoverable and reachable in every supported state.

For drawers: define opener, closer, Escape behavior where applicable, overlay behavior, focus behavior, route-change behavior and accessible state/name.

For collapsible desktop navigation: preserve route recognition and essential affordances; collapsed is not hidden.
