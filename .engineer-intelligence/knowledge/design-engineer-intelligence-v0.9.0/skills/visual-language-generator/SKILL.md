# Visual Language Generator

Define relationships, not a component kit:

- hierarchy contrast;
- geometry logic;
- spacing rhythm;
- typography behavior;
- color role;
- imagery treatment;
- surface/material behavior;
- motion character.

Use tokens after the language is coherent. Avoid aesthetic defaults without evidence.
