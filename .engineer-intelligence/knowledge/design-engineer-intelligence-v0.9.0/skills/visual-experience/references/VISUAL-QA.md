# Visual QA

Use four gates.

## Gate 0 — Production readiness

Before judging beauty, verify that the artifact is the correct production unit.

Check:

- concept board vs production asset correctly classified;
- unrelated UI/text/objects are not baked into isolated assets;
- resolution suits final usage;
- background/transparency is correct;
- asset can be independently versioned and integrated.

## Gate 1 — Asset

Is the individual visual production-worthy?

Check technical cleanliness, subject accuracy, edges/transparency, unintended
text, dimensions, and actual-size readability.

## Gate 2 — System

Does it belong to the product's visual system?

Check style, palette, perspective, lighting, line language, density, scale,
character identity, icon weight, and motion personality.

## Gate 3 — Context

Does it work in the actual screen/game?

Check hierarchy, contrast, real size, crop, responsive behavior, content density,
CTA competition, performance, dark/light surfaces, reduced motion, neighboring
assets, and state variants.

The final proof is the implemented surface, not the isolated export.
