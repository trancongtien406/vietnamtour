# Motion System

## Prime rule

Motion should explain change, confirm action, direct attention, express
personality, or preserve spatial/state continuity.

Do not animate merely because a library exists.

## Motion roles

- selection;
- navigation;
- enter/exit;
- confirmation;
- warning;
- loading;
- reward;
- character reaction;
- ambient/world motion.

## Intensity

```text
subtle       → hover, selection, minor feedback
expressive   → important completion or transition
celebratory → rare milestone/reward
```

## Technology routing

```text
simple UI transition → CSS/native
component gesture/layout → framework motion library
preauthored vector motion → Lottie/dotLottie when suitable
interactive stateful visual → Rive when justified
game world animation → sprite/skeleton/game engine
```

Reduced motion is a first-class experience.
