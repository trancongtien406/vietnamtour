# Responsive Transformation

For each major region specify: persist, condense, move, regroup, disclose, replace, or hide-with-alternative.

Breakpoints are chosen where layout/task behavior fails, not because a framework has default numbers.

Validate state continuity during resize and mode switches. Mobile must remain a coherent composition.

Read `../../references/responsive-state-model.md`.
