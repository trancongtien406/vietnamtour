# Interface Review / Critic Council

Review through product, interaction, visual, accessibility, engineering and originality lenses.

For each issue report: problem, evidence, severity, consequence and direction—not a mandatory replacement design unless requested.

Structural invariant failures are blockers. Read `../../references/eval-doctrine.md`.
