# Content Adaptation

Choose transformation according to task priority.

Possible strategies include priority columns, horizontal data region, record cards, drill-in lists, filter sheets, action overflow, stacked editor regions, step-based forms and progressive disclosure.

Do not automatically convert every table to cards or every toolbar to a hamburger. Preserve comparison tasks when comparison is primary.
