# Creative anti-pattern detector

Do not ban a visual pattern by name. Detect patterns used without purpose.

Challenge these when they appear by default:

- generic gradient blob hero;
- glass navigation without semantic benefit;
- bento grid used only because it is fashionable;
- walls of interchangeable rounded cards;
- oversized marketing typography on utility screens;
- decorative charts with no decision value;
- excessive pills and badges;
- random 3D/WebGL for perceived premium quality;
- copy-pasted dashboard metric grid unrelated to primary jobs;
- identical visual grammar across unrelated industries.

Ask: what user/product/context evidence makes this pattern belong here?
