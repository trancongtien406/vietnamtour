# Project memory

Project memory stores context and reasoning, not a page-template archive.

Bootstrap mode:

1. scan project structure;
2. identify design tokens and component primitives;
3. capture navigation/shell model;
4. capture product constraints;
5. record existing decisions and known failures.

Iteration mode:

1. load only relevant memory;
2. detect changes;
3. update affected decisions/corrections;
4. keep historical rationale when useful.

Never infer that a past visual treatment is mandatory merely because it exists in memory.
