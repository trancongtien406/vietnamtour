# Core principles

1. Product truth before style.
2. Standardize reasoning, not appearance.
3. Fixed / Varies / Judgment:
   - Fixed: accessibility, navigation availability, structural integrity, interaction semantics.
   - Varies: visual language, composition, typography, imagery, motion character.
   - Judgment: density, disclosure, navigation model, content transformation, animation depth.
4. Reference != answer.
5. Pattern != template.
6. Eval != golden design.
7. Mobile is a composition, not a collapsed desktop screenshot.
8. One signature idea is stronger than many decorative effects.
9. Existing design-system decisions are evidence; preserve them unless the task justifies change.
10. Every strong pattern must earn its place through product/user/context reasoning.
