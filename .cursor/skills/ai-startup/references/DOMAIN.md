# AI Product / Startup Domain Model

## Subtypes

- AI assistant
- agent platform
- generative media
- AI developer tool
- vertical AI
- automation agent

## Primary audiences

- business users
- developers
- operators
- buyers
- early adopters

## Common conversions

- try product
- book demo
- run example
- join waitlist

## Trust signals

- real examples
- evaluation/evidence
- limitations when relevant
- integration model
- security/privacy details

## Discovery questions for the agent

- Which subtype is this?
- Who makes the purchase/decision?
- Is the site primarily discovery, evaluation, transaction, booking, or lead generation?
- What proof exists and what must not be fabricated?
- What content/media is actually available?
- What industry cliché should be deliberately avoided?
