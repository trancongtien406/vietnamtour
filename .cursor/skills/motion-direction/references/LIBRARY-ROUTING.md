# Library Routing

## CSS

Use for low-complexity interactions:

- color
- border
- opacity
- tiny transform
- focus/hover transition

## Motion

Use for:

- presence
- shared layout
- spring feedback
- menu/modal/drawer
- drag/gesture
- component-level sequencing

## GSAP

Use for:

- multi-part timelines
- precise sequencing
- ScrollTrigger
- pinning
- scrubbed stories
- text/image cinematic reveals
- route transition choreography

## WebGL / Three.js

Use when the creative idea itself is:

- 3D product
- spatial field
- shader distortion
- physically meaningful particle system
- immersive environment

Do not use WebGL as a prestige badge.
