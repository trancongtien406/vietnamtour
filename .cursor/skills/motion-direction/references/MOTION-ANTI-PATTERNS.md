# Motion Anti-patterns

- every section fades upward
- bounce/elastic easing on serious brands
- long preloader with no technical need
- scroll-jacking
- pinning entire pages
- cursor follower hiding real pointer semantics
- animation that causes layout shift
- text scramble for long or critical text
- excessive blur filters on large surfaces
- continuous ambient loops everywhere
- hover effects on touch-critical actions
- conflicting easing families
