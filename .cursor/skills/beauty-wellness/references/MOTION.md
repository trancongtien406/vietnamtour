# Beauty / Wellness Motion Intelligence

## Strong opportunities

- material/texture reveal
- product macro transitions
- service accordion motion
- booking feedback

## Motion decision

Use motion only when it:

- reinforces the brand
- reveals a relationship or process
- preserves spatial continuity
- provides useful feedback

## Avoid

- generic beige minimalism by default
- unverified medical claims
- excessive soft gradients
- motion that obscures treatment details

## Production fallback

On mobile and reduced-motion contexts, preserve the same information and narrative using a simpler vertical/static form.
