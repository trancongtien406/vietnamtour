# Scroll Storytelling

Scroll interaction must encode meaning.

Use for:

- process progression
- product workflow
- architectural project sequence
- before/after transformation
- horizontal collection/gallery on desktop
- pinned copy with changing media
- technical diagram progression

Avoid for ordinary articles and simple feature lists.

## Production

- keep scroll distance proportional to information
- no traps
- mobile can switch to vertical static sequence
- provide reduced-motion linear content
- avoid excessive ScrollTriggers
- refresh after meaningful layout changes

See `references/RECIPES.md`.
