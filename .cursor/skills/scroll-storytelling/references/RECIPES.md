# Scroll Story Recipes

## Pinned copy + changing media

Best for:

- service process
- architecture case study
- SaaS workflow
Keep copy readable while media updates by chapter.

## Horizontal project gallery

Desktop only when project imagery benefits from breadth.
Mobile fallback: vertical cards or swipe gallery.

## Image expansion

Use to move from context to immersion.
Drive scale/crop from real viewport geometry rather than arbitrary values.

## Process timeline

Map progress to actual business stages.
Avoid decorative lines that do not reveal information.
