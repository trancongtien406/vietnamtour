# Typography Motion Recipes

## Line-mask reveal

Good for editorial and luxury.
Split by visual lines only when runtime layout is stable.
Reveal through overflow mask with vertical translate.

## Word reveal

Useful for responsive headlines because it survives line wrapping better than hardcoded line groups.

## Scramble

Use for short technical labels, states, counters.
Never use for paragraphs.

## Rolling labels

Use for playful navigation or CTA micro-interaction.
Keep final label readable at rest.
