# Interaction Motion

Use interaction to clarify affordance and relationships.

Candidates:

- project hover controls preview media
- card image subtly reframes
- nav indicator moves with current context
- CTA has stateful press/hover feedback
- gallery preserves spatial direction
- cursor follower only as decorative enhancement

Rules:

- essential information never depends on hover
- touch gets equivalent state
- keep response fast
- do not animate every card differently
