# Healthcare / Clinic Motion Intelligence

## Strong opportunities

- subtle reveal
- appointment state feedback
- service navigation transitions

## Motion decision

Use motion only when it:

- reinforces the brand
- reveals a relationship or process
- preserves spatial continuity
- provides useful feedback

## Avoid

- motion increasing cognitive load
- unverified outcome claims
- overly playful medical UI
- decorative animation on critical information

## Production fallback

On mobile and reduced-motion contexts, preserve the same information and narrative using a simpler vertical/static form.
