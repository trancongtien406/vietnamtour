# Architecture / Interior Studio Domain Model

## Subtypes

- architecture studio
- interior design
- residential studio
- commercial design
- multidisciplinary practice

## Primary audiences

- premium homeowners
- property developers
- commercial clients
- cultural/institutional clients

## Common conversions

- explore projects
- understand studio point of view
- start a project inquiry

## Trust signals

- completed projects
- project credits
- location/year/scale
- press/awards if verified
- process and team

## Discovery questions for the agent

- Which subtype is this?
- Who makes the purchase/decision?
- Is the site primarily discovery, evaluation, transaction, booking, or lead generation?
- What proof exists and what must not be fabricated?
- What content/media is actually available?
- What industry cliché should be deliberately avoided?
