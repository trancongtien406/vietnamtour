# Architecture / Interior Studio Motion Intelligence

## Strong opportunities

- project index hover preview
- image expansion
- pinned project chapters
- horizontal gallery on desktop
- plan/detail reveal

## Motion decision

Use motion only when it:

- reinforces the brand
- reveals a relationship or process
- preserves spatial continuity
- provides useful feedback

## Avoid

- SaaS feature cards
- generic construction icons
- excessive rounded UI
- random 3D objects unrelated to projects

## Production fallback

On mobile and reduced-motion contexts, preserve the same information and narrative using a simpler vertical/static form.
