# Page Transition Recipes

## Shared project image

Use when a work/listing preview is visually continuous with a detail hero.

1. capture source geometry
2. transition or clone visual layer
3. route/update content
4. resolve into target hero
5. restore normal document flow
Fallback: immediate navigation or simple fade.

## Curtain / mask

Use for editorial chapter changes and brand-led sites.
Keep duration controlled.
Do not use for every tiny utility route.

## Directional fade

Best default for application-like sections.
Use consistent direction tied to navigation hierarchy.
