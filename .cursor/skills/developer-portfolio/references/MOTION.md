# Developer / Engineer Portfolio Motion Intelligence

## Strong opportunities

- project hover preview
- shared project transition
- system/data-flow animation
- technical diagram progression

## Motion decision

Use motion only when it:

- reinforces the brand
- reveals a relationship or process
- preserves spatial continuity
- provides useful feedback

## Avoid

- fake terminal as entire identity
- skill percentage bars
- random Matrix aesthetic
- animation that hides project substance

## Production fallback

On mobile and reduced-motion contexts, preserve the same information and narrative using a simpler vertical/static form.
