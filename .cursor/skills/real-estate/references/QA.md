# Real Estate QA

## Domain fit

- [ ] subtype is clear
- [ ] primary audience is clear
- [ ] primary conversion is clear
- [ ] trust signals are visible and truthful
- [ ] page architecture matches the decision journey

## Visual fit

- [ ] art direction is justified
- [ ] imagery is appropriate to the domain
- [ ] typography supports the brand position
- [ ] design cannot be trivially relabeled for an unrelated industry

## Motion fit

- [ ] motion opportunities are domain-specific
- [ ] no prohibited/cliché effects dominate
- [ ] mobile fallback works
- [ ] reduced-motion version works

## Avoidance checklist

- [ ] not present: cinematic friction on search portals
- [ ] not present: fake property imagery
- [ ] not present: overlong intro loaders
- [ ] not present: hiding price/location
- [ ] not present: parallax on every image
